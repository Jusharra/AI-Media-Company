# Social Package Template

## Purpose
The master social distribution package — coordinates all social content deliverables for a featured founder across LinkedIn, Twitter/X, YouTube, and newsletter. Generated by the Media Producer agent after feature article is approved. Serves as the production brief for the distributor agent.

---

## Metadata Block
```
TEMPLATE: social-package
DOC_TYPE: social-package
SUBJECT: {founder_name}
COMPANY: {company_name}
INDUSTRY: {industry}
TIER: {starter|growth|authority}
FEATURE_ARTICLE_ID: {article_id}
FEATURE_URL: {signal_feature_article_url}
PACKAGE_GENERATED: {date}
STATUS: draft|approved|distributed
DISTRIBUTOR_AGENT_ID: {agent_id}
```

### 10. DISTRIBUTOR AGENT INSTRUCTIONS

```
TASK: Distribute social package for {founder_name} / {company_name}

PLATFORM_APIS_REQUIRED:
- LinkedIn API (post scheduling)
- Twitter/X API (thread posting)
- Newsletter platform API
- YouTube Data API (if uploading episode)

SCHEDULE:
{week_1_date}: LinkedIn Post 1 + Twitter Thread
{week_2_date}: LinkedIn Post 2 + Newsletter
{week_3_date}: LinkedIn Post 3 + YouTube Episode
{week_4_date}: Podcast Episode + Thought Leadership

ON_COMPLETION:
- Log all posted URLs in distribution_log table
- Update article/content status to 'distributed'
- Trigger performance_tracking_task after 7 days
- Alert lead agent with distribution summary

FALLBACK:
- If LinkedIn API fails: queue for manual post + alert
- If Twitter API fails: queue for manual post + alert
- Log all failures to distributor messages_out
```

## Approval Gate

Before distribution begins, this package requires Gate 4 (Distribution Gate) approval:
- Human reviewer confirms content is accurate
- Founder has signed off on all posts (email confirmation)
- All links are live and functional
- Performance tracking is configured
